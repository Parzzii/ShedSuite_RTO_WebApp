ShedSuite -> RTO Pro V7.14

AUTO-ASSIGNED BATCH MODEL + CONTRACT NUMBERS
- New ShedSuite/CSV contracts now receive the reserved next Model # automatically.
- Contract # automatically follows that Model # for normal ShedSuite rows.
- Sequential allocation remains batch-aware: 501, 502, 503... per model profile.
- Used buildings keep their original physical Model # and use the existing suffix workflow.
- Used rows do not consume a new-model number.
- Manual Model # and Contract # edits are preserved and are not overwritten by later saves/reorders.
- PDF contracts retain the PDF Model # and Agreement # rather than being overwritten by ShedSuite numbering.
