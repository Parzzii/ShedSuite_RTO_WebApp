ShedSuite -> RTO Pro V7.13

Batch model-number reservation
- Next Model suggestions now increment within the current contract batch.
- Example: if a model series starts at 501, the rows show 501, 502, 503... instead of all showing 501.
- Each model profile/series increments independently.
- Used buildings keep their existing model and do not consume a new-model number.
- Suggestions recompute when contracts are reordered, discarded, or toggled Used.
- Existing model/store/dealer/PDF/category behavior is otherwise unchanged.
