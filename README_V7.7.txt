ShedSuite RTO Web App V7.7

UI UPDATE
- Click the customer name/header to collapse or expand a contract card.
- Collapse All and Expand All are available above the review list.
- Drag the ⠿ handle to sort contracts up/down.
- Up/Down arrow buttons are also available.
- The new order is saved to the job immediately and rebuilds the RTO CSV/XML/ZIP in that order.
- Every contract now carries a hidden stable row id so reordering cannot cause Save/Discard/background certificate data to attach to the wrong person.
- Search/Needs Review filters temporarily disable sorting; clear them to reorder the full list.

Everything else remains based on V7.6.2.
